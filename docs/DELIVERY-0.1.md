# CoCraft 0.1 本地 Alpha

日期：2026 年 11 月 18 日。首轮由开发 Agent 直接实现，6.1-sol 子 Agent 做功能验收。实现从零应用代码开始；已有 PRD 与选定工作台设计作为输入。本轮从约 00:54 开发至 02:10 形成交付包，约 76 分钟；这是这轮实测，不作为以后迭代的速度承诺。

## 这次交付的东西

- `release/mac-arm64/CoCraft.app`：可打开的 Apple Silicon Mac 应用，包含媒体工具和内置 Skills。
- `release/CoCraft-0.1.0-mac-arm64.zip`：约 179 MB 的本机应用归档，解压即可获得上述 `.app`。
- `artifacts/CoCraft-coast-demo-1080p.mp4`：应用实际导出的 24 秒示例，1920×1080、H.264、30 fps、AAC 48 kHz，约 14.7 MB。
- 可继续演进的 TypeScript 源码、锁定依赖、构建脚本和功能检查脚本。
- 深色/浅色主题、可调整面板、命令面板、快捷键、焦点与对话框、拖放素材和时间线。

## 建议的第一遍体验

1. 打开应用，播放「沿海公路」。这份工程中的素材、标题和声音都可编辑。
2. 选择「片头 · 沿海公路」，在属性里换一句文案；按 L 锁定，再试试撤销/重做。
3. 导入自己的视频，拖进时间线；将播放头置于内部，按 ⌘B 分割，再拖动边缘裁切。
4. 用「新建成片版本」生成竖屏副本，调整构图；主片仍独立保存。
5. 「添加 → 编写自己的画面」，修改默认 TSX，编译并应用，再从属性面板改文案参数。
6. 连接模型，创建任务；可要求 Agent 读取 Skill、编写片头或调整选中片段。运行中可补充方向、停止、手动编辑与锁定。
7. 导出 MP4，然后关闭并重开工程，继续修改。

## 已验证

- 类型检查与生产构建通过。
- 工程 smoke：编辑、锁定保护、过期版本拒绝、停止后的发布拒绝、撤销重做、落盘重开。
- Pi smoke：真实 SDK 与工具执行，读取工程 → 写 TSX → 编译 → 原子发布；文件和 bash 写入越界被拒绝。模型响应来自本地协议夹具，**这不等于真实模型质量验收**。
- Electron 功能检查：真实播放、暂停、跳转、标题修改、锁定、分割、字幕导入编辑、独立竖版、代码组件、完整退出重开、MP4 输出。详见 [6.1-sol 验收记录](verification/electron-functional.md)。
- 真实视频 + WAV：3 秒视频裁出 2 秒，导出得到 H.264/AAC；AAC 封装尾部补齐约 5 ms，处于一帧以内。
- 完整示例导出：24 秒 1080p，视频与音轨均存在。
- 独立 `.app`：代码编译、实际画面检查、发布、完整退出恢复通过；Pi 工具链协议 smoke 在包内通过。
- 本地配音：通过包内媒体工具导入 3.33 秒中文 WAV，时长与音频素材登记正常。
- 失败保留：可编译但运行时抛错的组件被画面检查拒绝，发布版本及原组件保持不变。

验收中发现并修复了预览页握手竞态、提交失败仍显示成功、音频解锁探针被 CSP 拦截、预览边缘白底、包内 esbuild 执行路径和浅色主题波形对比度问题。

## 尚未替你验收的部分

- 没有读取或借用当前开发会话的模型凭据。接上你的模型后，才可评价 Agent 的创意、模型成本和复杂项目可靠性。
- Pexels 连接器需 API Key。未配置时有明确入口提示；本次没有虚构搜索成功或购买素材。
- 自动转录、按文稿语义删句联动视频、云端图片/视频生成、专业调色/HDR/多机位没有伪装为已完成。
- 任意第三方 Skill/依赖、超长素材、非常规编码、所有 macOS 版本尚未覆盖；当前目标是 macOS 15+、Apple Silicon、短片 SDR。
- 当前没有 Apple 开发者签名、公证或自动更新。Remotion 嵌入与媒体工具公开分发许可尚需在商业发行前确认。

## 下一轮应拿真实作品驱动

优先导入一份真实口播或旅行工程，接一个你实际使用的模型，用它检验：Agent 读素材的质量、连续修改时的节奏、人工接管的效率。随后补自动转录与语义剪辑、素材缺失重连、代码组件图形参数、资产检索/生成接口。底层保留 ProjectCore、AgentHost、RenderHost 边界，UI 和供应商适配器可以独立迭代。
