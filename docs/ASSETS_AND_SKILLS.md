# CoCraft 素材与 Skill 策略

日期：2026 年 11 月 18 日。状态：产品方案与首批内容计划。

素材入口覆盖用户导入、内置、搜索、生成和个人素材库。Agent 与用户使用同一套素材对象，找到、生成或编写的内容都能继续修改、替换和复用。

## 首批提供什么

| 类别 | 具体内容 | 接入顺序与成本性质 |
| --- | --- | --- |
| 字幕 | 普通双行、关键词强调、逐词高亮、双语、人物区分 | 首个内置包；本地参数化渲染 |
| 标题与包装 | 主标题、副标题、人物介绍条、章节卡、片尾、分屏 | 首个内置包；组件源码和参数保留 |
| 图表与说明画面 | 柱状或折线图、数字变化、标注、流程、路线 | 先做少量高质量组件，再由编码 Skill 扩展 |
| 背景与基础转场 | 纯色、渐变、纹理、淡入淡出、简单遮罩与移动 | 随首批组件加入；按帧确定 |
| 图片与视频补充镜头 | 风景、城市、活动、行业场景等 | 首个外部搜索候选为 Pexels，需可用连接 |
| 配音与生成图片 | 台词配音、插图、背景、需要补充的画面 | 在真实剪辑闭环后接入首个供应商；按用量计费 |
| 音乐与音效 | 转场、点击、环境声、背景音乐 | 内置少量具备分发依据的音效；音乐采用明确授权来源 |
| 视频生成 | 镜头生成、参考图驱动、重试候选 | 后续扩展；记录生成成本和实际采用率 |
| 个人素材库 | 品牌资产、常用包装、人物参考、已生成镜头和风格包 | 保存并跨项目复用，来源和访问范围保持清楚 |

先做约 12 至 20 个可调组件作为内容目标，逐个通过可读性、运动、画幅和实际成片检查；这是计划数量，不是现有库存。开发与演示优先使用自制测试素材，第三方素材保留许可和来源。

## 一个素材对象需要保存什么

- 稳定 ID、类型、时长、画幅、帧率、音频与透明通道等必要属性。
- 来源类型、供应商、原页面、作者、远端 ID、本地文件位置和内容标识。
- 适用许可链接、必要署名、取得时间和使用限制；支持时记录当时的许可版本或证据。
- 生成素材的模型、参数、提示、参考素材、任务 ID 和已知费用。
- 代码素材的源码、参数 schema、依赖锁定、版本和预览。
- 候选与采用关系，以及在哪些成片、片段中使用。

采用素材后固定工程引用和本地可用版本，避免远端链接或共享组件改变时悄悄改变成片。缓存可以清理，唯一的生成成果和原始素材分别管理。

## 搜索与生成如何进入工作流

Agent 根据叙事用途、时长、画幅、风格和预算判断合适来源。一般先复用项目或个人库里已经合适的内容，再考虑内置组件、搜索和生成；用户明确要求原创生成时遵循该方向。

已有授权和预算内可直接采用并保留候选，用户能在素材面板查看来源并换成另一项。供应商不可用时保留待补位置，继续完成其他部分。不能把搜索预览图误当成最终可用素材。

[Pexels API](https://www.pexels.com/api/documentation/) 提供图片与视频检索，并有平台链接、署名和使用规则；[素材许可](https://www.pexels.com/license/) 与 API 规则共同约束使用。原型阶段不建立第三方素材镜像库。

## 保留编码 Agent 与 Skill 生态

首个运行时建议 Pi，直接利用会话、编码工具和资源加载能力。应用增加项目上下文、预览、提交与导出工具，避免重写一套不完整的编码循环。[Pi SDK](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/sdk.md)

遵循标准目录：`SKILL.md`、`scripts/`、`references/`、`assets/`。发现阶段读取名称与描述，相关任务才加载完整说明和资源。[Agent Skills 规范](https://agentskills.io/specification)

| Skill 来源 | 处理方式 |
| --- | --- |
| 内置 | 随应用锁定经过验证的版本与依赖 |
| 项目 | 与工程目标和素材一起保存，可进入版本记录 |
| 用户选择的本地目录 | 显示发现结果、来源和依赖，在授权范围内使用 |
| 外部仓库或资源包 | 保留来源、版本、许可和兼容信息，再启用 |

兼容 SKILL.md 格式不等于具备其要求的 Python、浏览器、MCP、供应商账号或宿主专用工具。界面显示缺少哪些能力；不能静默忽略步骤后声称执行了该 Skill。

## 首批工作流

1. **视频片段处理**：检查媒体、抽帧、转码、裁切和音频处理。
2. **代码画面与包装**：利用 Remotion 现有最佳实践，生成参数化标题、图表和动画，渲染检查后加入工程。[Remotion Skills](https://www.remotion.dev/docs/ai/skills)
3. **字幕与文稿**：转录接入、时间对齐、术语校正、字幕样式与安全区检查。
4. **素材搜集与归档**：按镜头用途找候选、记录来源、导入采用项。
5. **交付检查**：缺失素材、黑帧候选、字幕溢出、音频峰值、时长与输出参数核对。

这些是计划中的工作流，不代表目录内已有可运行 Skill。先运行一个真实工作流，再将稳定步骤整理成项目 Skill，避免仅写说明文件就计为完成。

## 可编程素材的复用

Agent 写好的图表或标题，除了当前渲染结果，还应保留源码、参数和一个可复现示例。用户可将其保存到“我的素材库”，用于下一支片子，也可连同选择和检查流程形成 Skill。

代码组件版本固定后再被成片引用；更改公共组件生成新版本。人工调整和锁定遵循 [技术架构](ARCHITECTURE.md) 的发布规则。
