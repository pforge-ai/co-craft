# CoCraft 0.3.0 交付说明（全栈修复、双层资产、分镜候选与 3D 演示舞台）

交付日期：2026 年 11 月 18 日
实际开发与验证耗时：约 85 分钟

---

## 一、 运行与打包入口

- **开发构建与桌面启动**：
  ```bash
  npm run build
  npm start
  ```
- **macOS Apple Silicon 原生应用包**：
  - 路径：`release/0.3/mac-arm64/CoCraft.app`（可通过 `npm run package` 重新生成）
- **自动化全量验收命令**：
  ```bash
  npm run test:unit     # 核心数据模型、SRT、CoW、波纹删除、预检与 Scope 强校验单测
  npm run test:ui       # 窗口分栏拖拽、设置各页签尺寸、焦点与快捷键回归测试
  npm run test:v03      # v0.3 零闪屏、画布操控、双层资产库、分镜多候选、Three.js 3D 与 MP4 导出端到端验收
  npm run smoke:models  # 多提供商路由、SSRF 拦截、转录分块、生成恢复与 Pi Agent 协议烟测
  ```

## 二、 本轮核心交付成果

1. **根治 0.2 全部 25 项底座与交互缺陷（阶段 ①）**
   - **零闪屏预览与模态框焦点修复**：移除 `preview.tsx` 按 `revision` 重挂载 `<Player>` 的缺陷；修复 `Modal` 抢占关闭按钮焦点导致搜索框失焦的问题；打通预览 iframe 快捷键转发（`Space`、`J/K/L`、`⌘K`、`T`、`⌘Z`）。
   - **像素级专业时间线与可交互舞台**：`px/sec` 无级缩放（支持 `⌘+滚轮` 与 `>400%` 精剪）、自适应 `MM:SS:FF` 帧标尺、移动与裁切双端磁吸提示、视频音轨真实波形提取、可调音视频淡入淡出、轨道静音；暂停态画布直接拖拽平移缩放（`StageOverlay`）与坐标打点引用给 Agent。
   - **工程可靠性与安全加固**：`.cocraft/revisions-index.json` O(1) 版本索引、静默化内部组件编译验画作业、导出前预检（Preflight）与离线文件一键重连（Relink）、组件跨成片写时复制（CoW）、Agent `steer` 消息严格保序、`/render/` 严格无网络 CSP、云端下载 SSRF 环回拦截与 `sandbox-exec` 敏感目录拒绝。
   - **品牌焕新**：全新光学双光圈 `.icns` 应用图标（10 张标准 `.iconset`，消除黑灰旧图标底部阴影截断）与清澈钴蓝工作台色板。

2. **双层资产体系（Asset v2）与双模分镜编排台（阶段 ②）**
   - **Project Vault ⇄ Global Library（`electron/vault.ts` + `AssetVaultPanel.tsx`）**：内置主体一致性锚点（角色/产品/环境）、品牌色板规范、舞台/3D 装置、TapNow 式生产配方及本地媒体/3D 模型五大类资产，支持跨项目一键沉淀与独立快照引入。
   - **双模工作台与多候选 Takes（`StoryboardStudio.tsx`）**：顶栏一键切换「舞台剪辑」与「分镜编排」（`<Player>` 保持挂载零重载）；支持单分镜多候选（`T1 / T2...`）实时切换对比、分镜前后重排、绑定主体一致性锚点并交由 Agent 定向精修。
   - **重叠窗口转录与文稿精剪联动**：长音频 4 秒 Overlap 分块转录与中点去重、结果持久化缓存、文稿词句检索、一键铺入时间线字幕及单句切片入轨。

3. **Three.js 3D 舞台与「8 合 4」科普/演示动画矩阵（阶段 ③）**
   - **单一 `Remotion + Three.js` 3D 引擎（`ThreeStage.tsx`）**：内置同轴涡轮镜组、半导体芯片算力叠层、微缩高并发产线沙盘三套程序化 3D 结构，支持导入 `.glb/.gltf` 模型并按质心径向平滑爆炸拆解（`explode`），同时开放 `three` 与 `@remotion/three` 给自定义/Agent 代码组件。
   - **4 大创造 Skill + 录屏聚焦窗**：落地 `cocraft-seecode`、`cocraft-tinycharts`、`cocraft-anatomy`、`cocraft-teardown-3d` 四套内置 `SKILL.md` 与对应无代码预设装置，以及 `screen-focus-rig` 录屏弹簧平滑聚焦窗。
   - **3D 预演转生成参考（Previs-to-Video）**：舞台顶栏相机按钮（`stage.captureReference`）一键将当前三维透视构图捕获为项目主体参考真值资产。

## 三、 可复现步骤

1. 启动应用后点击顶栏 **「分镜编排」** 切换至分镜工作台，点击 **`+ 3D 拆解镜`** 或在既有镜头点击 **`+ 候选`** 创建第二个候选版本，切换 `T1 / T2` 观察时间线实时同步且相邻镜头不位移。
2. 切回 **「舞台剪辑」** 选中 3D 拆解片段，在右侧 **「属性」** 面板切换三维结构模板（涡轮/芯片叠层/产线沙盘）、机位预设（环绕/等轴测/推轨）并拉动 `爆炸拆解度`；点击舞台右上角 **相机图标** 将当前构图捕获为参考真值资产。
3. 在左侧 **「资产」** 面板切换「本项目资产」与「全局个人库」，新建角色主体卡沉淀至全局库，新建空白项目后从全局库一键引入。
4. 点击右上角 **「导出」** 查看自动导出预检（Preflight）并导出 H.264 MP4 成片。

## 四、 已知边界与下一项最小目标

- **已知边界**：
  1. 当前预览画布直接操控支持 2D 图层平移与四角缩放；Three.js 3D 相机视角目前通过属性面板预设（`orbit / isometric / dolly-in / top-down / hero-low`）或代码控制，尚未提供画布直接拖拽三维轨道球（OrbitControls Gizmo）。
  2. 云端生图、生视频、语音转录及编码 Agent 需用户在「设置 → 提供商」中填写自有 API Key 后真实执行；未配置凭据时界面明确引导连接，绝不用模拟输出冒充完成。
- **下一项最小目标（v0.4）**：为 3D 舞台增加暂停态画布鼠标三维旋转摆机位（Orbit Gizmo）与关键帧曲线微调面板。
