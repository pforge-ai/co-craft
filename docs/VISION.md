# CoCraft 产品愿景与能力边界

日期：2026 年 11 月 18 日（v0.3 架构对齐更新）。

CoCraft 是一款面向创作者与小型团队的 **「可编程创造 + AI 分镜资产 + 专业剪辑」一体化桌面视频工作台**。

它不仅能剪辑已有视频，更能**从零创造画面**：无论是严谨的产品演示、技术架构图解、手绘状态科普、Three.js 3D 机械爆炸拆解，还是像 TapNow / UpDream 那样具备角色与产品一致性的 AI 生成镜头，都在同一套**双层资产体系**与**双模工作台**中完成创作、预览、局部接管与多画幅交付。

当前已完成 `0.1` 与 `0.2` 基础闭环；以下定义升级后的核心产品形态与能力边界，实际能力按阶段构建与真机验收推进。

## 核心定位：为什么是「既有创造，也有剪辑」

行业现有工具割裂在两个极端：
- **纯云端 AI 视频画布（如 TapNow、UpDream）**：擅长多模型抽卡、角色资产锁定与分镜生成，但面对**清晰文字排版、产品 UI 演示、数据图表、精密算法/科学机制图解、确定性 3D 结构拆解**时，扩散模型画不准字、控不住逻辑，且缺乏帧级时间线精剪能力。
- **纯编码动画 Skill 或传统剪辑软件（如独立 HTML Skill / Premiere / CapCut）**：单跑编码 Skill 只能吐出孤立的网页，无法与配音、字幕、实拍素材混排导出；传统剪辑软件则缺乏原生编码 Agent 与资产一致性生成工作流。

CoCraft 将两条路线统一在同一工程内核（**Remotion + Three.js + FFmpeg + Pi Coding Agent**）之上：
1. **确定性可编程创造**：用 React、SVG 与 Three.js（`@remotion/three`）直接生成矢量超清的演示甲板、数据架构（`SeeCode`）、手绘状态机（`Tinycharts`）、精密剖面遥测（`Anatomy/Anima`）与 3D 机械拆解/流转（`Teardown/Machine/Factory`）。
2. **一致性 AI 资产与分镜编排**：吸收 TapNow / UpDream 的资产锚定（Ground Truth）、镜头多候选重拍（Takes）与可复用配方（Recipe），支持用 3D 舞台机位抽帧反哺 AI 视频首尾帧控制。
3. **随时接管的专业剪辑**：双模切换「分镜与资产编排台」与「像素级多轨时间线 + 画布直接操控」，人工锁定、局部批注与版本回退贯穿始终。

## 一次理想的创作过程

创作者新建「新一代引擎发布与原理科普」项目，从**全局个人资产库**一键引入品牌的配色排印规范、产品外观图与主讲人音色资产，放入一段实操录屏视频，然后告诉 Agent：

> 做一支 90 秒的产品与原理短片：前 15 秒抛出痛点；中间用精密剖面图和 3D 爆炸视图拆解核心架构为什么快 3 倍，穿插那段实操录屏并自动放大聚焦关键按钮；结尾做一页干净的对比总结。再派生一条 30 秒竖版精华。

1. **分镜与资产编排**：Agent 先拆解出清晰的「场与分镜卡（Shots）」，绑定品牌资产与参考图。缺少实拍的段落，自动选用 `Anatomy` 剖面范式与 `Teardown` 3D 拆解范式编写可参数化组件；实操录屏自动挂上平滑推拉聚焦参数（`CameraFocus`）。
2. **随时预览与直接操控**：播放全程丝滑无闪屏。创作者觉得第三镜的 3D 爆炸幅度不够，直接在右侧属性面板把 `explode` 滑块从 `0.5` 拉到 `0.85`，并在画布上直接拖拽调整标题位置、锁定该镜头。
3. **多候选对比与局部重做**：对开场 AI 概念镜头不满意，在该分镜卡上点「重拍候选（New Take）」，保留原镜头的同时生成新候选，一键切换对比采用。
4. **资产沉淀**：片中写得极好的「3D 双核拆解装置」连同参数与配方一键保存到**全局资产库**，下一期视频换组参数与模型即可直接复用。

## 四类核心场景共用同一底座

| 场景 | Agent 完成的创造与剪辑工作 | 创作者掌控的决策 |
| --- | --- | --- |
| **科普解释与技术拆解** | 调用图解/剖面/3D 拆解 Skill 编写确定性动画、生成配音与时间轴对齐字幕 | 科学/技术准确性、核心比喻、视觉密度与拆解节奏 |
| **产品发布与演示动画** | 编写分步演示页（Deck Scene）、高保真交互动效、录屏平滑聚焦放大、数据图表 | 卖点顺序、品牌调性、关键交互停留时长 |
| **口播访谈与知识解说** | 音频重叠分块转录、文稿联动精剪、自动补充 B-roll 或动态信息图 | 论点保留、气口呼吸感、补充画面取舍 |
| **AI 叙事短片与多平台派生** | 主体/角色资产一致性锚定、3D 机位预演抽帧、多候选镜头组装、横竖屏重构图 | 角色设定、选定候选镜头（Take）、各平台画幅构图 |

## 分阶段演进路径

### 第一阶段：坚实的专业底座（修复顽疾 + 交互与时间线重构）
彻底消除预览重挂载闪屏、快照全量读取卡顿与安全边界漏洞；落地基于 `px/frame` 的专业无级缩放时间线、全吸附裁切、视频波形、画布直接拖拽缩放（Direct Manipulation）、快捷键全链路响应、素材离线检测重连与导出前质量检查（Preflight）。

### 第二阶段：双层资产体系与分镜编排台
将平铺的“本地素材”全面升级为结构化**资产（Asset v2）**，打通「当前项目资产（Project Vault）」与「全局个人资产库（Global Library）」；落地双模工作台中的「分镜与资产编排台」，支持镜头资产绑定、多候选重拍（Takes）切换、文稿联动与可复用配方（Recipe）。

### 第三阶段：科普/演示动画矩阵与 3D 舞台
基于单一 **Remotion + `@remotion/three`（Three.js）** 渲染内核，落地「8 合 4」可编程创造 Skill 矩阵（`SeeCode` 数据架构、`Tinycharts` 手绘状态推演、`Anatomy/Anima` 精密剖面遥测、`Teardown/Machine/Factory` 3D 拆解与流转）及录屏聚焦包装组件；预留 `.glb/.gltf` 3D 模型资产加载与 3D 机位预演（Previs）接口，平滑衔接未来的重度建模与空间导演能力。

## 能力边界与诚实原则

| 能力 | 我们追求的标准 | 明确保持的边界 |
| --- | --- | --- |
| **演示页与录屏工作流** | 用 Remotion 分步演示组件 + 导入录屏的平滑聚焦包装实现超清可改效果 | 首阶段不重复造系统级桌面录屏采集器，也不引入冗余的外部 Slide 框架 |
| **科普与 3D 动画** | 代码与 Three.js 按帧确定性渲染，暴露核心业务参数供 UI 无代码微调 | 复杂工业级 CAD/高精度多边形雕刻在专业建模软件完成后以 GLB/GLTF 资产导入 |
| **外部 Skill 兼容** | 内置精选 4 大范式，同时支持读取社区标准 `SKILL.md` 并转化为工程组件 | 外部独立网页型 Skill 需经组件化适配或受控沙箱校验后方可进入成片发布 |
| **主体一致性与分镜** | 双层资产库锁定参考图、提示词锚点、音色与 3D 机位参考帧 | 云端视频生成最终画质与物理一致性仍受所连模型本身能力约束 |
