# CoCraft 产品愿景与能力边界

日期：2026 年 11 月 18 日。

希望做成的 CoCraft，是一个可以持续合作的视频创作工作台。创作者交给它想法、参考、现有素材和约束；它完成组织内容、寻找或生成材料、编写画面、剪辑和检查；创作者通过预览与局部修改掌握方向。每次工作留下可编辑工程、可复用素材，以及能够看懂和恢复的版本。

以下场景描述产品目标。当前已完成的是产品文档和交互原型，实际能力通过逐轮构建验证。

## 一次理想的创作过程

用户新建“产品发布”项目，放入录屏、几张产品图片和一页说明，然后说：

> 做一支 60 秒的介绍片。先说明问题，再演示三个功能，最后给出使用场景。字幕克制，像我们上一支片子。再准备一个 30 秒竖版。

Agent 先形成简短结构，并立即开始能确定的工作。它整理录屏中的有效片段，寻找合适的补充画面，写一个可修改的标题动画，用数据画出一张图。配音和画面陆续就绪，工作台出现可播放的段落；缺少素材的地方有明确占位。

用户不必等整片做完。看到第二段时可以说“这一段慢一点”，或者直接拖长镜头、修改标题，锁定必须保留的一句。Agent 读取新的工程状态，继续调整其他部分。

觉得结尾不合适时，可以要求两个方案：一个有行动号召，一个安静收尾。两版共享素材，各自保留剪辑与代码状态。用户比较后采用一个结尾，横版与竖版分别导出。

下次再做同系列内容时，字幕、片头、配色、节奏约定和可用素材已经在项目库里。Agent 可以复用，也能在用户明确调整风格后更新约定。

## 三类工作都落在同一个工程里

| 输入 | Agent 希望能完成的工作 | 创作者主要做的决定 |
| --- | --- | --- |
| 一段访谈或口播 | 转录、按主题组织、删重复和停顿、补画面、字幕、短版 | 原意、必须保留的表达、节奏与情绪 |
| 一个选题、资料与零散素材 | 整理脚本、镜头清单、配音、搜索素材、代码图表与动画、组装初剪 | 观点、事实、视觉风格、重点与取舍 |
| 已有工程和修改意见 | 定位修改、局部重做、统一包装、横竖版与短版派生 | 选定方案、品牌表达、最终审片 |

AI 镜头、用户视频、搜索得到的素材与代码画面都是可追溯的工程内容。只提供成片 MP4 时，操作范围由成片中实际可分离的内容决定。

## 分三层实现

### 最早可用的闭环

导入一段视频，加入一个 Agent 编写的标题组件；用户修改参数并锁定；Agent 继续编辑；导出并重新打开工程。验收对象是一次真实的创作交接，使用短素材和有限效果。

这时就应具备现代桌面工作台的基本手感：清晰的选区、连续的预览、可靠的撤销、稳定的焦点、可记住的布局。素材搜索、配音等连接能力可以按下一轮需要加入。

### 能用于日常创作的工作台

三类场景各能交付真实短片；有文稿、分镜和时间线联动；素材、Skill、代码组件和版本可复用。面对重复修改，Agent 保留人工选择，能定位自己做过的改变，并从错误或中断处继续。

基准以 1080p SDR、1 至 5 分钟成片逐步验证。30 至 60 分钟源素材与多轨播放属于后续基准测试，不能从短片演示推断已经达标。

### 可以持续积累的小型创作工作室

一个系列有自己的风格、角色资料、品牌素材和工作流；多个剪法可以独立探索；每个被采用的代码组件和镜头成为以后可用的材料。对团队逐步增加审片批注、交付打包和工程交换。

这里的价值来自持续复用和可控修改。高级色彩、复杂音频、多机位、HDR 与多人协作按实际需求演进。

## 能力达到什么程度

| 能力 | 我们应追求的程度 | 必须保留的边界 |
| --- | --- | --- |
| 明确指令执行 | 裁切、移动、样式、画幅和版本操作有可验证结果 | 达不到约束时报告原因，不能静默改别处 |
| 内容初剪 | 能理解主题和结构，形成有价值的第一版 | 原意、事实、敏感表达需要创作者审阅 |
| 图表与包装 | 编码生成可复现、可参数化的视觉内容 | 任意代码不保证拆成全部可视图层 |
| 素材寻找与生成 | 给出适用候选，记录来源、版本和成本 | 可用性、版权范围和生成质量取决于来源 |
| 审美判断 | 能根据参考、反馈与约定持续接近目标 | 不能保证一次达到导演审片标准 |
| 剧情和角色一致性 | 候选管理、参考资料与镜头级重试 | 不能保证自动生成整部连贯的长篇影视作品 |
| 专业工程互通 | 清楚说明可导出元素与降级方式 | 不承诺任意 PR 或剪映工程无损往返 |

## 如何判断这件事值得继续做

1. 用户愿意拿真实项目继续做，并实际采用成片。
2. 用户能在任何阶段接管，修改后继续交给 Agent，连续多轮仍能理解和控制工程。
3. 新效果可以通过 Skill、脚本或代码组件做出来，无需每次等应用增加一个专用按钮。
4. 先前的字幕、素材、组件和风格约定确实减少下一次的重复劳动。
5. 开发以小时级可运行增量推进，进展由构建和验收证明。
