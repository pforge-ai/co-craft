# CoCraft 0.2.0

适用于 Apple Silicon 和 macOS 15 及以上。已有工程继续从本机的 CoCraft 工作空间打开。0.1 的模型设置会复制到新版目录结构，原加密设置留有本地备份。升级时先退出旧版，再打开应用。[工作台](../release/0.2/mac-arm64/CoCraft.app) · [压缩包](../release/CoCraft-0.2.0-mac-arm64.zip)

## 三分钟体验

1. 选择「文件 → 新建示例工程」。播放《相位之间》，在横版和竖版之间切换。看第 2 秒的摄影构图和第 12 秒的波形排版。
2. 在时间线点击「添加」。选择一项标题或信息图形，修改文案、预览横竖版，再加入时间线。进入「摄影与声音」可试用唱针、雨巷或山脊画面，试听转场与底乐。「载入随附素材包」可载入有源码和参数的品牌署名组件。
3. 点击「新会话」，直接输入“在主片第 8 秒添加一条持续 3 秒、文案为『现场录音』的动态角标”。首次发送会自动命名。选中片段可以调整其属性、引用给 Agent、锁定或撤销修改。
4. 点击「导出」。播放与导出会固定各自使用的工程版本，后台作业完成后可以打开成片。[横版 1080p](../artifacts/CoCraft-Phase-Study-1080p.mp4) · [竖版 1080p](../artifacts/CoCraft-Phase-Study-vertical.mp4)

## 模型与素材

| 位置 | 能做什么 |
| --- | --- |
| 设置 → 提供商 | 设置连接地址、协议和凭据，检测端点提供的模型。也可手工录入部署 ID。 |
| 设置 → 模型 | 同一提供商可登记多个模型，分别声明用途、实际接口、音色、时长和画面尺寸等适用参数。 |
| 设置 → 用途默认值 | 分别指定剪辑、画面理解、转录、配音、图像、视频的全局和项目默认值。会话模型与单个素材作业可单独选择。 |
| 素材 → 素材工作室 | 生成图像、视频和配音，分析已有图像或视频，识别音频或视频的语音。完成结果保留在后台作业；有时间段的转录可按源素材入点对齐成字幕。 |
| 动态素材库 → 让 Agent 定制 | Agent 取得同一份素材定义，也可编写新 TSX、导入源码包、编译预览并一次性发布。项目可增添标准 SKILL.md。 |

工作台的新标志、窗口边界和玻璃效果可在实际应用里查看。开启或关闭玻璃、切换深浅色都在「设置 → 外观」。[工作台实拍](verification/v2/v02-workbench-dark.png) · [浅色设置](verification/v2/v02-settings-light.png) · [完整素材库](verification/v2/v02-library-full.png)

## 本机交付与外部发行

发行 ZIP 的 SHA-256 为 `73cd622d9c8f3f6cb152a4aa874565139bdb08127a08c47ca26cd51f5294dde1`。已验证压缩包完整性和解包后应用的签名。

提取压缩包后直接打开其中的 CoCraft.app。本版本采用本机 ad-hoc 签名。macOS 识别到应用签名变化时，首次使用已保存的模型可能会要求允许 CoCraft 读取钥匙串。系统凭据异步读取，等待期间可继续编辑或停止连接中的 Agent。提供商密钥继续由系统加密存储。应用从本机读取并渲染编辑媒体，向远端模型发送的内容取决于用户选用的具体功能。

本轮的真实账户接入为 DeepSeek 剪辑，云图像、云视频、云配音及视觉供应商使用协议夹具验收。公开发行还需要 Developer ID 签名、Apple 公证以及相应的第三方商业分发许可。Pexels 在线搜索需要用户自己的凭据。导出优先使用本机 Chrome 或 Chromium，首次获取渲染浏览器可能需要联网。[依赖与分发](THIRD_PARTY.md)
