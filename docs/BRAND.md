# CoCraft 品牌视觉与图标规范

更新日期：2026 年 11 月 18 日（v0.3 视觉焕新规范）。

## 反思：为什么 0.2 的图标很糟糕

0.2 版本的图标本质上是把两段生硬的二维平面 `<path>` 贴在一块死气沉沉的灰黑渐变底板上：
1. **毫无体积感与材质生命力**：既没有 macOS 原生图标应有的三维次表面散射（Subsurface Scattering）、通透折射与高光边缘（Rim Specular），又用阴沉的工业深灰配惨白折角，显得廉价、冰冷、像上世纪的硬件驱动工具。
2. **低级工程瑕疵**：阴影滤镜在 `1024 × 1024` 底边直接被硬裁切出一条直线，`icon.iconset` 目录里还混入了非标准尺寸的预览图。

## 0.3 图标与品牌美学标准（macOS Sequoia 级立体光学质感）

对标现代顶级桌面创意与 Agent 应用的图标水准——融合 **通透彩色果冻/棱镜叠色（如 TapNow）**、**温润白底衬托高饱和立体柔光体积（如 Codex 桌面端紫蓝立体云）**、**利落三维空间折面（立体莫比乌斯结构）** 与 **电影级体积光画幅切割（双画幅剪接 + 丁达尔光束）** 的共同设计精髓：

1. **拒绝扁平 2D 贴片，追求真实三维光学体积（Volumetric & Tactile Materiality）**
   - 图标主体必须具备明确的**三维厚度、景深层次、内发光/次表面通透感与顶部细腻高光边（Rim Light）**，而非简单的 SVG 线性渐变填色。
   - **主选方案（白瓷底座 · 立体流光棱镜画幅）**：
     - **底座**：Apple 标准 `1024 × 1024` 画布内居中 `824 × 824` 连续曲率超椭圆（Continuous Superellipse），温润珠光白（`#FFFFFF` → `#F3F5FB`）配微立体边缘厚度，在深浅壁纸与侧边/底部 Dock 上都清透跳脱。
     - **核心立体形态**：以 **「交叠的三维圆润画幅 / 棱镜快门（Co-Craft Prism Frames）」** 为核心符号——融合**电光钴蓝-薰衣草紫（Cobalt → Periwinkle Violet）**的主体积块与**暖桃珊瑚 / 晨光青翠**的半透明折射层，交叠处呈现晶莹的磨砂玻璃/果冻混色与微妙高光，中间自然透出精巧的「双帧剪接 / 舞台镜头」负空间，一眼传达“AI + 代码创造与影像剪辑共创”。
   - 实现阶段可通过 WebGL/Three.js 物理光照着色或高精度分层渲染管线生成母版纹理，再经光学锐化产出全套 `.iconset`，告别手写简陋 `<path>` 的廉价感。

2. **工作台内 `BrandMark` 与 UI 色彩焕新**
   - 工作台顶栏与欢迎页的 `BrandMark` 与应用图标保持同源色彩基因（流光钴蓝紫渐变 + 暖珊青翠折射点缀，小尺寸自动收拢为高辨识度立体双帧流光徽标）。
   - 工作台界面摆脱 0.2 灰扑扑的暗紫调：审片区严守中性黑/纸白保证画面色彩准确，交互强调色升级为清澈有活力的 **电光钴蓝（Cobalt，`#3B82F6`）**，资产卡片、分镜标签与 Agent 状态采用柔和的光学渐变微光点缀，兼顾专业审片克制感与现代创意工具的精致度。

3. **严格的 macOS 图标工程验收规范**
   - `824 × 824` 超椭圆安全区外圈严格保持柔和阴影自然衰减至 `0` Alpha，四周边缘 `12 px` 内严禁出现任何非零像素截断。
   - `resources/icon.iconset` 只允许存放 Apple 标准 10 张 PNG（`16` 至 `512@2x`），预览校样图统一输出到 `docs/verification/`。
   - 打包与验收时同步清理旧版残留 `.app`，并在真实 macOS Dock（含侧边栏小尺寸与放大态）下截图复核。
