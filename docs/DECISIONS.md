## 已替代的前提

- “两名全职工程师、按周月交付”已被用户纠正为“由开发 Agent 实现、小时级迭代”。原始估算保存在归档 PRD 中，不再作为当前开发计划。
- “完整 Swift 原生工作台优先”是先前技术建议，当前建议改为 TypeScript 路线，原生模块按实测瓶颈增加。
- “只有固定剪辑工具的 Agent”不符合用户要求。保留自由编码与脚本能力，在版本发布处保障工程正确性。
- “所有视频都来自用户导入”不足以满足产品愿景。素材、代码生成与外部服务共用素材模型。

## 0.1 实现记录（11 月 18 日）

- 用户授权直接开发到高阶方向，由 6.1-sol 子 Agent 做功能验收；只保留必要 smoke。
- Electron 45.3.3、React 19.3.1、Pi 1.5.2、Remotion 4.0.544 已锁定并进入实际构建。开发时曾用已缓存 Electron 43.2.0 验证流程，交付构建已升级；不将旧运行时作为发行依赖。
- JSON 快照与发布指针先实现，SQLite、Git worktree、原生桥按实测需要引入。
- 独立预览 frame 与渲染进程已实现；工作台、Player 和导出使用统一工程语义。
- 配音先接 macOS 已安装系统语音，保证不配置云模型也可试用；Pexels 保留实际连接器，需要用户 Key。
- 工具链通过真实 Pi SDK + 本地模型协议夹具验证，不将协议通过描述为真实模型创作能力验收。
- 第三方扩展默认不加载。标准 Skill 文本、源码和可选受限脚本构成第一阶段生态入口。
- 首次启动采用深色 Graphite，设置支持 Paper 浅色及跟随系统；替代初期原型的默认跟随系统建议。
- 首个构建目标为 macOS 15+ Apple Silicon；这是当前包体的边界，不是用户已确认的长期兼容范围。

## 0.2 工作台与生态

- 设置窗口由视口决定固定边界，侧边分类与内容滚动分开。玻璃材质用于标题栏、播放控制和浮层。时间线采用明确的轨道色，重叠片段各有点击区域。图标与应用内标志使用同一套双色分段 C 形几何。
- 用户与 Agent 共享参数化预设、素材 ID、不可变组件和版本发布入口。源文件包记录版本、依赖及媒体指纹。常规用户从预览和属性面板操作。开发者可编辑工作区副本后发布。
- 单独维护提供商连接和模型能力。Agent、画面理解、语音转录、配音、图像、视频各有用途默认值，可被当前工程和单次任务覆盖。密钥属于提供商。会话模型和工程版本分别持久化。
- 图片、声音、文本结果和视频作业都经过同一后台服务。远端视频 ID 与原始连接随作业持久化，可以继续查询同一次提交。Agent 暂存媒体并通过编辑发布应用到工程。
- 首发保留现有工程和项目索引。新版示例通过文件菜单新建；真实模型验收使用独立示例项目。公开发布与本机签名构建分开记录。
