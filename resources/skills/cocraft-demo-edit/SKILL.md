# 产品功能演示剪辑规范

本规范仅定义叙事节奏与剪辑法则，视觉配色请始终读取项目当前激活的视觉风格（`project.vault` 中的 `style` 资产），不锁死固定色板。

## 叙事结构与镜头时长

1. **三秒直入痛点或结果**：开场前 `2.5–3.5` 秒直接展示核心价值或最终效果，不铺垫冗长片头。
2. **一镜一动作**：每个软件操作镜头控制在 `3–6` 秒，只聚焦一个关键点击或状态变化；使用设备外壳组件或 `focalX / focalY / scale` 将观众视线推向操作区域。
3. **声画反馈对齐**：关键点击处可在音轨对齐轻巧点击音效（`role === "sfx"`），章节切换对齐柔和空气转场音，底乐音量控制在 `18%–25%` 避让人声频段。
4. **收尾定量印证**：演示动作结束后跟进 `3–4` 秒的数据对比或结论卡，给观众留足阅读时间。
