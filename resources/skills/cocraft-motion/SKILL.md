# 为镜头设计动态素材

先用 `read_project` 取得最新版本、目标成片、帧率、用户选择、保护片段和素材。打开创作约定，确认这几秒观众应当看到什么变化。保留用户已定的原文、镜头、数据和署名。优先完成用户点名的镜头。

## 选择画面

用 `list_presets` 查当前目录及参数。再检查工程中的 `components` 和已有品牌素材。根据内容选择处理方式。

- 补摄影或声音时调用 `list_studio_media` 查看随附库。按返回的 ID 调用 `prepare_studio_media({id})`，取得已复制的 `asset`。在同一组操作中添加该素材与引用 `asset.id` 的画面或音频片段。唱针特写适合展示接触点，城市和山景可建立地点，短音效对齐动作，底乐预留人声空间。这条路径可离线执行。
- 采访或口播保留人物焦点。人物条用于首次出现，字幕保留真实断句。在没有词级时间戳时，分词强调只表示设计节拍。精确口型或逐词字幕以实际时间戳为依据。
- 数据说明先确定比较的量、单位、范围和出处。双项比较共用零点和尺度；单个已知数值可用计数。用户没有提供测量数据时，改用能直接展示操作或过程的图形。
- 主体摄影适合透明标题或标注。选择主体旁已有的留白，避免大面积遮挡。一幅画面通常只需一个主要阅读焦点。把另一个事实放进接下来的镜头，或由后续变化揭示。
- 对同频声波、轨道或参数变化等过程，直接从帧号计算图形。内置「相位实验」可控制起止相位和变化时长。替换实验参数后同步检查相关解说、图例和独立音频。
- 原有可编辑组件适用时，先改它的参数；需要新的运动关系时，在任务工作区写默认导出的 React / Remotion 组件。使用工程素材 ID，通过 `assetUrl(id)` 读取媒体。通过 `compile_component` 取得可发布对象，保留作者和来源。

## 排入成片

1. 使用成片的实际 fps 将秒转换为整数帧。按动作或旁白定起止，给关键数字和长句留下阅读时间。预设的默认时长是起点。
2. 用 `prepare_preset({presetId, sequenceId, start, duration, props})` 准备内置对象。参数键、颜色格式、枚举和数值范围以本次目录结果为准。复用已有实例时，通过 `updateClip` 只改目标 `props`，保留稳定 ID 和人工调整。
3. 组合时让背景占视觉轨，标题、说明和图形占叠加轨，字幕占字幕轨。有底色的整幅图形会覆盖下面的镜头。长文案在短边安全区内换行，竖版优先纵向排布。需要同时交付双画幅时，对两条成片分别安排构图与出现时间。
4. 将准备好的 operation、已登记媒体及对应片段一次交给 `publish_edit`，使用刚读取的 `baseRevision`。代码组件连同 `putComponent`、引用它的代码片段一起发布。锁定片段引用的组件保持原版本。遇到版本冲突重新读取，并对用户正在编辑的内容保留选择。

例如把同一镜头做成采访开场，可以先在真实照片或视频上叠人物条；受访者开始讲话时才从转录中取字幕。向 `prepare_preset` 分别传 `lower-third` 和 `glass-caption`，设置不互相遮挡的时间，用一组操作发布。只需改颜色时，一次 `updateClip` 就足够。

## 看实际帧

调用 `preview_frame({sequenceId, frame})`，帧号相对于整条成片。选择能判断问题的位置，例如标题完全进入后、图形正在变化时、下个片段出现之前。对竖版另取实际帧；检查最长中文、重点颜色、摄影焦点、下沿字幕与人物条是否相撞。遇到问题，修改具体字号、文案断行、时间或位置，再取同一帧复核。

工具返回 PNG 时查看图片；返回视觉模型分析时，注明分析到的内容。相邻静帧可检查位置变化，连续的播放节奏和声音需实际播放或导出验证。报告改动所在成片、时间点、版本和实际检查结果。如果预览服务或视觉模型未配置，说明已成功完成的步骤以及尚待核对的画面。
