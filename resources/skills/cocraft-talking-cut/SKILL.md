# 口播与访谈精剪规范

本规范仅定义口播剪辑与信息补充方法论，配色与字体遵循当前项目选用的视觉风格。

## 核心剪辑法则

1. **按文稿切句去冗余**：优先读取音视频资产上的持久化时间戳文稿（`transcript.segments`），剔除重复口误、语气词与超过 `0.6` 秒的无意义停顿；保留逻辑转折处的自然换气（`0.15–0.25` 秒）。
2. **防爆音软切口**：裁切人声视频/音频片段时，保持 `0.04–0.06` 秒微淡入淡出，避免波形零点截断产生咔哒声。
3. **短句高可读字幕**：单行中文不超过 `16` 字（竖屏不超过 `13` 字），按语义自然断句，去掉句末多余句号。
4. **关键概念视觉托底**：在主讲人首次出场叠加身份条，在抛出复杂概念、对比数据或分步结论的 `4–6` 秒区间，叠加对应的动态图解或标注卡，消除纯大头画面的视觉疲劳。
