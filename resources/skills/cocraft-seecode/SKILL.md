# SeeCode · 数据架构与分步演示页范式

当用户需要系统架构演进、多方案基准评测、代码原理走读或发布会级章节演示页（Deck）时，启用本范式。

## 快速选择：内置装置 vs 新编组件

1. **优先复用参数化装置**：若镜头是 2–4 阶段的流水线架构 + 底部核心指标，直接用 `prepare_preset({presetId: "seecode-architecture", sequenceId, start, duration, props: {text, subtitle, nodes: "阶段A|阶段B|阶段C", metrics: "指标1 · 指标2 · 指标3", activeStep, accent, surface}})`。
2. **定制深度图解组件**：需要多分支拓扑、对比柱状矩阵、时间轴高亮或代码片段逐行聚焦时，在工作区编写 `.tsx` 组件并通过 `compile_component` 编译发布。

## 视觉与动画铁律

- **高对比克制配色**：深空底色（`#090e1a`）或纯净纸白（`#f8fafc`），仅保留 **1 个主强调色**（如钴蓝 `#3b82f6`）标示当前活跃节点，其余节点降为低饱和石板灰（`#334155` / `#94a3b8`），绝不堆砌彩虹渐变。
- **帧驱动分步揭示（Progressive Reveal）**：按 `useCurrentFrame()` 与 `fps` 计算各阶段入场与点亮节拍（每阶段间隔 `0.35s–0.8s`），让观众视线一次只锁定一个事实。
- **双画幅自适应**：用 `const portrait = height > width * 1.1` 自动切换横向流转（`row` + `→`）与竖版流转（`column` + `↓`），两侧留足 `7.5%` 安全边距。
- **暴露无代码参数**：将标题、节点文案、核心数值与强调色设为默认导出组件的 `props` 默认值，便于用户在右侧属性面板随时微调数字与措辞。
