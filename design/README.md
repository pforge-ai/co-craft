## 当前界面关系

- 左侧按项目和任务组织工作；切换到素材时复用左侧空间。
- 中间标签页打开主片、竖版、创作约定等内容；成片与会话分别管理。
- 右侧显示当前任务及明确的编辑目标，选区可引用到指令。
- 下方时间线、文稿和修改记录互相定位；代码组件后续通过参数面板编辑。
- 聚焦剪辑时可以收起项目导航；默认保留适合协作的平衡布局。
- 外观默认跟随系统，当前强调色为克制的蓝灰。浅色与深色都应保持清楚的层级和文字对比。
